# 默认使用中文写文档

## 默认规则

除非用户明确要求其他语言，或仓库已有更高优先级的语言规范，否则在这个 skill 仓库中默认使用简体中文编写以下内容：

- README
- `SKILL.md`
- 设计文档、方案文档、计划文档、变更说明
- 其他说明性文档

## 适用边界

- 这个 skill 默认约束文档与说明性内容，不自动把“代码注释必须中文”扩展为仓库级规则
- 如果当前文件已经长期使用英文，且需要保持上下文一致性，优先保持原风格
- 用户明确指定英文或其他语言时，以用户要求为准

## 保持原文的内容

以下内容默认保持原文，不做中文化改名或翻译：

- 命令、路径、环境变量
- 标识符、函数名、类名、变量名
- API 名、协议字段、错误码、配置键
- 需要精确复制的外部文本或模板内容

## 执行方式

- 新建文档时，默认直接用中文写作
- 修改既有中文文档时，继续保持中文
- 修改既有英文文档时，先遵循仓库原风格；若没有明确要求，不主动做全文翻译
- 在中英文混合不可避免时，解释性内容优先中文，技术标识保持原文

## 何时不要强行用中文

以下情况优先级高于本 skill：

1. 用户明确要求英文或其他语言
2. 当前仓库已有明确语言规范，且需要保持一致
3. 面向外部发布的文档已有既定英文标准
4. 第三方模板、上游同步文件、协议生成文件不适合改写语言风格

## 自检

提交前快速检查：

- 新增或修改的说明性文档是否默认使用中文
- 是否误改了命令、路径、标识符、字段名或配置键
- 是否把应保持英文风格的既有文档错误地改成了中文
- 是否违反了用户或项目已明确的语言约束
