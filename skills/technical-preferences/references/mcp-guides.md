# MCP 服务的操作指南

设计或审查需要跨工具操作指南的 MCP 服务时，沿用 datamarket 的做法：

- 在 `initialize` 响应的 `instructions` 中简述服务用途、何时读取哪个主题，以及指南工具名。详细步骤按主题读取。
- 提供只读指南工具（如 `datamarket_get_guide`）。省略 `topic` 时返回主题目录，指定 `topic` 时返回正文。相关业务工具的描述提示对应主题，让仅支持 Tools 的客户端也能发现指南。
- 将可由用户选择的工作流程同时作为 MCP Prompts 提供。`prompts/get` 与指南工具共用正文模板和渲染入口，相同主题和参数得到相同正文。

验收时检查初始化响应的指引、仅通过 Tools 获取目录和正文的路径，以及两种入口返回的正文是否一致。
