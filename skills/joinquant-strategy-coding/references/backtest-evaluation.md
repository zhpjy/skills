# 回测评价口径

回测评价的目标不是证明策略“好看”，而是判断它在真实约束下是否仍值得继续研究或进入实盘。

## 先看什么

- 收益率是否有意义地跑赢所选基准
- 最大回撤是否在用户能承受的范围内
- Sharpe / Sortino 是否稳定，而不是只靠少数极端行情拉高
- 换手率是否与策略频率、资金规模和费用假设匹配
- 在真实手续费、最低佣金和滑点下，收益是否仍成立

## 再看什么

- 不同起点是否稳定，而不是只在单一起点漂亮
- 牛市、震荡、市值风格切换阶段是否都能解释
- 回撤修复时间是否过长
- 收益是否依赖少数个股、少数月份或少数极端行情
- 组合是否对某类行业、风格或市场单边暴露过重

## 必须警惕的假象

- 年化收益高，但换手极高，真实费用下不可用
- 回撤低，但长期明显跑不赢基准
- 回测曲线平滑，但资金规模一放大就失效
- 少量参数改动后表现大幅塌缩，说明过拟合嫌疑高
- 只有最近一段时间表现好，跨阶段不稳定

## 推荐输出口径

向用户汇报时，至少给出：

- 回测区间
- 初始资金
- 手续费、最低佣金、滑点假设
- 基准
- 收益率
- 最大回撤
- Sharpe / Sortino
- 交易次数或换手率
- 主要风险暴露或失效场景

## 决策原则

- 收益高但执行不可落地，不推荐
- 回撤低但长期无超额，不推荐
- 需要极端理想化费用假设才成立，不推荐
- 多起点、多阶段下都基本成立，才值得继续推进
